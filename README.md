# MediBro
Medical Healthcare Management System
AI-Powered Prescription Analysis & Medication Management System

MediBro is an intelligent healthcare assistant designed to streamline prescription analysis and enhance medication management. Built using a Streamlit frontend and Flask backend, MediBro leverages OCR, Natural Language Processing (NLP), and AI models to extract, interpret, and organize information from handwritten medical prescriptions.

🚀 Key Features
Handwriting Recognition (OCR): Accurately extracts text from scanned or photographed prescriptions.

Medical Entity Recognition: Identifies medicines, dosages, timings, and instructions using AI-powered NLP.

Smart Medication Management: Organizes extracted information into a user-friendly format for both patients and healthcare providers.

Multi-Language Support: Built-in translation capabilities to support prescriptions written in various languages.

Interactive UI: Simple and responsive interface using Streamlit for fast deployment and easy interaction.

🛠 Tech Stack
Frontend: Streamlit

Backend: Flask

OCR Engine: Tesseract

NLP & AI Models: spaCy, Transformers

Translation: Google Translate API

Storage & Processing: Pandas, NumPy

🎯 Use Case
MediBro is ideal for healthcare systems aiming to digitize handwritten prescriptions, reduce human error in medicine dispensing, and enhance accessibility for patients across different languages and literacy levels.
